# FastAPI do Zero

A hands-on backend development project built while following the [FastAPI do Zero](https://fastapidozero.dunossauro.com/estavel/) course by [Eduardo Mendes](https://github.com/dunossauro).

This repository documents my journey learning backend development with Python and FastAPI, focusing on building REST APIs, writing automated tests, and applying software engineering best practices.

## Tech Stack

The project uses or will introduce the following technologies throughout the course:

- **Python** — Programming language
- **FastAPI** — Web framework
- **Poetry** — Dependency and environment management
- **Ruff** — Linting and code formatting
- **Pytest** — Automated testing
- **SQLAlchemy** — Database ORM
- **Alembic** — Database migrations
- **PostgreSQL** — Relational database
- **Docker** — Containerization
- **GitHub Actions** — Continuous integration

## Project Overview

The main project is a **Task Management REST API**, developed incrementally throughout the course.

The application will cover:

- User management and CRUD operations
- Authentication and authorization with JWT
- Task creation, retrieval, updating, and deletion
- Database persistence and migrations
- Automated testing
- Containerization and deployment
